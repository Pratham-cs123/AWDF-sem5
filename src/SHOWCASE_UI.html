How Practical 07 Works

1. Password Hashing (bcrypt)

Passwords are never stored in plaintext. They are salted with a cost factor of 10 and hashed before being saved in MongoDB.

2. JWT Signature & Claims

Login issues an encoded JSON Web Token containing header, claims (userId, role), and a cryptographic HMAC-SHA256 signature.

3. Route Guard Middleware

Protected endpoints inspect the Authorization: Bearer <token> header. If missing or invalid, an immediate HTTP 401 Unauthorized is returned.

Cache Invalidation & Trade-offs

Why invalidate on writes?

Without invalidation on POST, PUT, DELETE, read queries return outdated cached data (stale read anomaly).

TTL (Time-To-Live) Trade-off

Short TTL (10s) guarantees freshness but increases DB queries; long TTL (10m) maximizes speed but risks stale snapshots.

Faculty Lab Evaluation Q&A

Q: Why does emit() not block the response?

In Node.js, the HTTP response headers and body are flushed to the socket synchronously. Event listeners executing async timers (setTimeout) run on the event loop queue without delaying the response.

Q: When NOT to use EventEmitter?

In high-scale production systems with multiple servers, in-memory events are not shared across processes and will be lost on crash. Use distributed queues like RabbitMQ or Redis BullMQ instead.

Security & Graceful Degradation

Why proxy through backend?

Never expose OpenAI/Gemini keys in frontend code or Git history. Backend acts as secure gatekeeper.

Graceful Degradation Guarantee

If third-party AI APIs time out or keys are omitted, the backend catches the error and generates a heuristic suggestion. The application NEVER crashes.
